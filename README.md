# BroCodes 🐝 — 3D Interactive Honeybee Showcase

> An executive 3D web experience engineered with Three.js, GSAP ScrollTrigger, and bespoke shader tinting.

Designed and developed by **[BroCodes](https://brocodes.space)**.  
Founder & Lead Architect: **Avi Bhosale**.

---

## 🌟 Highlights

- **Interactive 3D Honeybee Model:** Real-time 3D glTF asset (`bee_model.glb`) with continuous wing oscillation and skeletal physics.
- **Scroll Choreography:** Synchronized 4-stage GSAP camera rotations (`#banner`, `#intro`, `#description`, `#contact`).
- **Live Studio Palette:** Real-time mesh material color customization (Golden Amber, Emerald Hive, Cyber Violet, Obsidian Tint) with persistent lighting calculations.
- **Milky Pearl & Deep Charcoal Themes:** Executive colorways tailored for showcase clarity.
- **Watermark-Free Assets:** Cleaned, custom-prepared high-resolution visual assets.

---

## 🛠️ Tech Stack

- **Three.js** (WebGL 3D Rendering & Lighting)
- **GSAP (GreenSock)** (Scroll-driven 3D Transform Choreography)
- **HTML5 / CSS3 / ES Modules**
- **glTF / GLB 3D Pipeline**
